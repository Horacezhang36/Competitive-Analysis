# Skill: HTML Report Generator
# 高质量 HTML 报告生成技能

## 描述
生成专业、美观的 AI 竞品分析 HTML 报告，支持响应式布局、动态图表、交互式元素。

## 设计规范

### 视觉风格
- 主题: 深色科技风 + 现代简约
- 配色方案:
  - OpenAI: #412a75 → #6b3fa0 (紫色渐变)
  - Google: #4285f4 → #34a853 (蓝绿渐变)
  - Claude: #8b4513 → #cd853f (橙色渐变)
  - 背景: #0d1117 (深色) / #ffffff (浅色)
  - 强调色: #58a6ff (蓝色链接)
  - 成功: #3fb950
  - 警告: #d29922
  - 错误: #f85149

### 布局结构
```
┌─────────────────────────────────────────┐
│  Header (Logo + 标题 + 生成时间)         │
├─────────────────────────────────────────┤
│  Navigation (Tab 导航)                   │
├─────────────────────────────────────────┤
│  Executive Summary                      │
├───────────────────┬─────────────────────┤
│  Product Cards   │  Feature Compare    │
│  (产品卡片)        │  (功能对比)          │
├───────────────────┴─────────────────────┤
│  Detailed Analysis Tabs                 │
│  ├── OpenAI                            │
│  ├── Google AI                         │
│  └── Claude                            │
├─────────────────────────────────────────┤
│  Comparison Matrix                      │
├─────────────────────────────────────────┤
│  Market Analysis                        │
├─────────────────────────────────────────┤
│  Trend Prediction                       │
├─────────────────────────────────────────┤
│  Footer (Disclaimer + Links)           │
└─────────────────────────────────────────┘
```

### 必需模块
1. **Hero Section**: 报告标题 + 关键指标卡片
2. **Company Tabs**: 三家公司独立标签页
3. **Product Grid**: 产品卡片网格布局
4. **Comparison Table**: 可排序的对比表
5. **Timeline**: 产品发布时间线
6. **Trend Charts**: 趋势图表（CSS 绘制的简单图表）
7. **Source Citations**: 带链接的引用列表

### 交互特性
- Tab 切换动画
- 卡片悬停效果
- 平滑滚动导航
- 响应式布局（移动端适配）
- 打印友好样式

### 性能要求
- 单文件 HTML（内联 CSS/JS）
- 首屏加载 < 1 秒
- 图片懒加载
- 可离线访问

## 技术实现
- 纯 HTML5 + CSS3 + Vanilla JS
- 无外部依赖
- Google Fonts (Inter)
- CSS Grid + Flexbox 布局
